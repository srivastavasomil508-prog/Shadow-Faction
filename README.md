#  ShadowFaction

ShadowFaction is a simple browser-based action game made using **HTML, CSS, and JavaScript**.

##  About the Game

In ShadowFaction, you play as a shadow warrior who has to survive against enemies coming from different directions.

The goal is simple:

**Move → Aim → Attack → Survive → Get the highest score!**

##  Features

* Player movement
* Enemy AI that follows the player
* Shooting system
* Health system
* Score system
* Increasing enemy waves
* Game Over screen
* Restart button
* Mouse and keyboard controls
* Dark shadow-themed game design

## 🎮 Controls

| Control        | Action           |
| -------------- | ---------------- |
| W / ↑          | Move Up          |
| S / ↓          | Move Down        |
| A / ←          | Move Left        |
| D / →          | Move Right       |
| Mouse Click    | Shoot            |
| Restart Button | Restart the game |

##  Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML5 Canvas

##  How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Start playing!

You can also use the **Live Server** extension in VS Code.
